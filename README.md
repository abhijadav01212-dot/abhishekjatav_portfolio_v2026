# Personal Portfolio Dashboard

A modern and responsive personal portfolio dashboard designed to showcase my technical skills, certifications, projects, and professional journey in Data Analytics, Business Intelligence, AI, and Software Development.

---

##  About The Project

This portfolio serves as my professional digital identity, allowing recruiters, clients, and professionals to explore my projects, technical expertise, certifications, and achievements through a clean and interactive interface.

The dashboard combines modern UI design with data visualization to provide an engaging user experience while highlighting my skills and portfolio.
